Conhecendo o DOM

O que é o DOM?

DOM significa Documento Object Model.

É uma representação do documento HTML em forma de objetos, organizada em uma estreutura hierárquica de árvore, conhecida como DOM tree.

Note que cada elemento do HTML está conectado. Chamadados esses elementos de nó (node) dentro dessa estrutura.

Em outros palavras, o navegador basicamente transforma o HTML em uma estrutura que o JavaScript consegue acessar e manipular.

Para que serve o DOM?

O DOM permite que o JavaScript intereka com os elementos HTML. Exemplos:

  • Selecionar elementos: Encontrar um botão
  • Alterar conteúdo: Alterar o texto de um parágrafo, titulo, etc.
  • Alterar estilo: Alterar a cor de um botão, tamanho da fonte, etc.
  • Criar elementos: Criar novo parágrafo, botão, links etc.
  • Remover elementos: Remover parágrafo, botão, links etc.
  • Capturar eventos: Detectar cliques, teclas pressionadas, etc.
  • Modificar atributos: Alterar um src, um arial-label, etc.
